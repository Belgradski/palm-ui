# palm-ui

Минималистичная библиотека React-компонентов для ваших проектов.

## Установка

```bash
npm install palm-ui
```
## Для локальной разработки и просмотра документации выполните:

```bash
npm run storybook
```
Storybook будет доступен по адресу http://localhost:6006.

## Компоненты
Button – кнопка с вариантами primary, secondary, danger и размерами sm, md, lg.

SmartTooltip – всплывающая подсказка с авто-позиционированием.
